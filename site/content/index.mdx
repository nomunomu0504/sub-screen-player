## What it does

<CardGrid>
	<Card title="Live frames at 60 fps" icon="rocket">
		Encoding and sending run in parallel. When frames arrive faster than the display takes them,
		only the newest one is sent.
	</Card>
	<Card title="Clock and dashboard" icon="seti:clock">
		A built-in clock with your own formats and colors, and a dashboard of CPU, memory, network and
		disk use.
	</Card>
	<Card title="Your own figures" icon="list-format">
		Scripts send values (a CI status, a queue) that show up as dashboard panels, and a panel shows
		how much Claude Code you have used.
	</Card>
	<Card title="Images, videos and web pages" icon="seti:image">
		PNG, JPEG, GIF and WebP fitted to the panel, animations included; videos through ffmpeg; any
		HTML page through headless Chrome.
	</Card>
	<Card title="Draw from any program" icon="puzzle">
		An HTTP and WebSocket API: stream frames from a script, a dashboard or a game.
	</Card>
	<Card title="Set and forget" icon="laptop">
		Starts at login, and carries on with what it showed when the display is replugged.
	</Card>
	<Card title="Secure by default" icon="approve-check">
		Listens on localhost only and refuses requests from web pages. Network access needs a token.
	</Card>
	<Card title="Built to be extended" icon="open-book">
		Device protocols live in small driver crates. Adding a display only means writing its
		protocol.
	</Card>
</CardGrid>
