import { Code, Steps, Tabs, TabItem, Aside } from '@astrojs/starlight/components';
import InstallCommand from '../../../components/InstallCommand.astro';

<Steps>

1. **`ssp` をインストールします。** インストーラーが、お使いの環境向けの最新リリースをダウンロードし、SHA-256
   チェックサムを確認してから、`ssp` を `PATH` の通った場所に置きます。

   <Tabs syncKey="os">
   	<TabItem label="macOS / Linux">
   		<InstallCommand os="unix" />
   		`~/.local/bin` にインストールします（`SSP_INSTALL_DIR` で変更できます）。
   		[Homebrew](https://brew.sh) を使う場合は次のとおりです（あとの更新も Homebrew で行えます）。
   		<Code code="brew install nomunomu0504/tap/ssp" lang="sh" />
   	</TabItem>
   	<TabItem label="Windows">
   		<InstallCommand os="windows" />
   		`%LOCALAPPDATA%\Programs\sub-screen-player` にインストールし、`PATH` に追加します。
   		[Scoop](https://scoop.sh) を使う場合は次のとおりです（あとの更新も Scoop で行えます）。
   		<Code code={'scoop bucket add nomunomu0504 https://github.com/nomunomu0504/scoop-bucket\nscoop install nomunomu0504/ssp'} lang="powershell" wrap />
   	</TabItem>
   </Tabs>

   [アーカイブを自分でダウンロード](../download/)したり、
   [ソースからビルド](https://github.com/nomunomu0504/sub-screen-player/blob/main/README.ja.md#インストール)したりもできます。

2. **Linux の場合のみ: ディスプレイへのアクセスを許可します。** udev ルールを入れて反映します（ディスプレイを
   挿し直しても反映されます）。

   ```sh
   curl -fsSL https://raw.githubusercontent.com/nomunomu0504/sub-screen-player/main/contrib/linux/70-sub-screen-player.rules \
     | sudo tee /etc/udev/rules.d/70-sub-screen-player.rules > /dev/null
   sudo udevadm control --reload-rules
   sudo udevadm trigger --action=add --subsystem-match=hidraw
   ```

   このルールは、PC の画面の前でログインしている人と、`plugdev` グループにディスプレイを使わせます。`plugdev` は、
   デスクトップなしで使う PC（SSH で使う Raspberry Pi など）のためです。Debian・Ubuntu・Raspberry Pi OS では最初の
   ユーザーが `plugdev` に入っています。そうした PC で Web ページも表示するなら、
   [ブラウザ用のライブラリ](../cli/#web-ページを表示する)も入れてください。

3. **ディスプレイをつないで、デーモンを起動します。** 時計が表示されます。

   ```sh
   ssp serve
   ```

4. **別のターミナルで、いくつかコマンドを試します。**

   ```sh
   ssp devices                    # ディスプレイ一覧
   ssp show photo.jpg --fit cover # 画像を表示
   ssp clock --no-seconds         # 秒なしの時計に戻す
   ssp brightness 60              # 明るさ（%）
   ```

5. **ログイン時に自動で起動するようにします。** `ssp serve` を Ctrl-C で止めてから実行します。

   ```sh
   ssp service install
   ```

   Linux では、ログアウトするとデーモンも止まります（SSH の切断も同じです）。ログアウト後も動かし続け、PC の起動時に
   始めるには（Raspberry Pi など）、次を実行します。

   ```sh
   sudo loginctl enable-linger $USER
   ```

</Steps>

<Aside type="tip" title="うまく動かないときは">
デーモンを止めて `ssp selftest` を実行してください。USB から画面表示までをひととおり検査し、どこで失敗しているかを
教えてくれます。[トラブルシューティング](../cli/#トラブルシューティング)も参照してください。
</Aside>
