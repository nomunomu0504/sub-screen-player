## 表示のパターン

<ScreenGallery lang="ja" />

`[clock]` や `[dashboard]` は設定ファイルの項目です（`ssp config init` で作成できます）。それぞれの設定例は [README](https://github.com/nomunomu0504/sub-screen-player/blob/main/README.ja.md#表示のパターン) と[コマンドラインガイド](cli/)にあります。

## インストール

<Tabs syncKey="os">
	<TabItem label="macOS / Linux">
		<InstallCommand os="unix" />
	</TabItem>
	<TabItem label="Windows">
		<InstallCommand os="windows" />
	</TabItem>
</Tabs>

あとは `ssp serve` を実行すると、ディスプレイに時計が表示されます。詳しくは[はじめに](getting-started/)を参照してください。

## できること

<CardGrid>
	<Card title="最大 60fps のライブ表示" icon="rocket">
		エンコードと送信を並行して行い、ディスプレイが受け取れる速さを超えてフレームが届いたときは最新のものだけを送ります。
	</Card>
	<Card title="時計・ダッシュボード・画像" icon="seti:image">
		書式や色を変えられる時計と、CPU・メモリ・ネットワーク・ディスクの使用状況を並べるダッシュボードを内蔵。PNG・JPEG・GIF・WebP の画像もパネルに合わせて表示します。
	</Card>
	<Card title="どんなプログラムからでも描画" icon="puzzle">
		HTTP と WebSocket の API で、スクリプトやダッシュボード、ゲームからフレームを送れます。
	</Card>
	<Card title="入れたら放っておける" icon="laptop">
		ログイン時に自動で起動し、ディスプレイを挿し直しても表示を続けます。
	</Card>
	<Card title="安全な初期設定" icon="approve-check">
		localhost でのみ待ち受け、Web ページからのリクエストは拒否します。ネットワークに公開するにはトークンが必要です。
	</Card>
	<Card title="拡張しやすい作り" icon="open-book">
		機種ごとのプロトコルは小さなドライバに分かれています。新しい機種への対応は、そのプロトコルを書くだけです。
	</Card>
</CardGrid>
